# AI Engineering Course

Self-paced AI engineering course: 15 modules from LLM foundations to RAG, agents, MCP, LLMOps and AI system design, with exercises, builds and a flagship RAG project.

The syllabus follows the Year 1 structure of Scaler's *Advanced Program in AI & Agentic Systems*, studied self-paced with Claude as tutor. Every module is done in full, nothing skipped, and cloud work is done on **Azure**.

## How each lesson works

**Concept → exercise → review → next lesson.** No lesson is marked done until its exercise has been reviewed.

Each lesson has its own folder inside its module:

```
01-ai-native-foundations/
└── lesson-1.1-how-llms-work/
    ├── notes.md       # lesson notes
    ├── exercise.md    # questions and my answers
    └── ...            # any code for the lesson
```
